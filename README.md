# buurtapps-agenda

Server-gerenderde agenda's voor iframes in het Businessapps-CMS (werkt met sandbox="", geen JavaScript).

- `/beauforthuis` : agenda Beauforthuis. Oude activiteiten (begintijd voorbij, Nederlandse tijd) verdwijnen direct.
- `?h=2950` : hoogte van de iframe in pixels. Het aantal kaarten wordt daarop afgestemd. Gebruik dezelfde waarde als `height` in de iframe.
- `/health` : status en cache.

Bron wordt hooguit eens per uur opgehaald. Geen externe pakketten.
